# 打包脚本旧版本残留修复计划

## 问题根因

两层缺陷导致旧版本包残留并传播到 `dist/`：

1. **插件 pack 脚本**：只删除当前版本的 zip（`rm -f "$OUT_DIR/包名-版本.zip"`），不清理旧版本的 `.tgz`/`.zip`/`.vsix`。版本号从 0.1.0 → 0.3.0 后，`*-0.1.0.tgz` 和 `*-0.1.0.zip` 永远留在 `dist/`。
2. **根 build 脚本**：`build_module` 清理了根 `dist/plugin/<name>/` 目录，但随后用 `cp -f` 从插件的 `dist/` 复制**所有** `*.tgz/*.zip/*.vsix`（含旧版本），把脏文件重新传播进来。Desktop 同理，Tauri bundle 目录中旧版本安装器也被全量复制。

## 修复方案

在每个 pack 脚本的 `npm pack` / `vsce package` / `zip` **之前**，用 glob 清理同包名的旧版本产物。根 build 脚本不需要改动（插件 `dist/` 干净后，复制结果自然干净），但 desktop bundle 需要额外处理。

### 1. codex / kimi-code / qwencode `pack.sh`（3 个文件，模式相同）

在 `mkdir -p "$OUT_DIR"` 之后、`npm pack` 之前，加：
```bash
# 清理旧版本产物，避免版本迭代后残留
rm -f "$OUT_DIR"/agent-aura-<name>-*.tgz "$OUT_DIR"/agent-aura-<name>-*.zip
```
其中 `<name>` 分别是 `codex`、`kimi-code`、`qwencode`。

### 2. codex / kimi-code / qwencode `pack.ps1`（3 个文件）

在 `npm pack` 之前，加：
```powershell
Get-ChildItem -LiteralPath $OutDir -File -ErrorAction SilentlyContinue | Where-Object { $_.Name -like "agent-aura-<name>-*.tgz" -or $_.Name -like "agent-aura-<name>-*.zip" } | Remove-Item -Force
```

### 3. claude `build.sh` / `build.ps1`

在 `npm pack` 之前，加旧版本清理：
```bash
# build.sh
rm -f "$OUT_DIR"/agent-aura-claude-*.tgz "$OUT_DIR"/agent-aura-claude-*.zip
```
```powershell
# build.ps1
Get-ChildItem -LiteralPath $OutDir -File -ErrorAction SilentlyContinue | Where-Object { $_.Name -like "agent-aura-claude-*.tgz" -or $_.Name -like "agent-aura-claude-*.zip" } | Remove-Item -Force
```

### 4. copilot `pack.sh` / `pack.ps1`

vsix 生成在项目根目录（无 `dist/`），在 `vsce package` 之前加：
```bash
# pack.sh
rm -f *.vsix
```
```powershell
# pack.ps1
Get-ChildItem -LiteralPath $ProjectDir -Filter "*.vsix" -File -ErrorAction SilentlyContinue | Remove-Item -Force
```

### 5. qwenpaw `pack.sh` / `pack.ps1`

在 `mkdir -p "$OUT_DIR"` 之后、`rm -f "$ZIP_PATH"` 之前，加：
```bash
# pack.sh — 清理旧版本 zip，保留 index.js
rm -f "$OUT_DIR"/${PLUGIN_ID}-*.zip
```
```powershell
# pack.ps1
Get-ChildItem -LiteralPath $OutDir -File -ErrorAction SilentlyContinue | Where-Object { $_.Name -like "$PluginID-*.zip" } | Remove-Item -Force
```

### 6. 根 `build.sh` / `build.ps1` — Desktop bundle 清理

Desktop 的 Tauri 安装器在 `target/release/bundle/` 中也会累积旧版本。在收集安装器之前，清理目标目录中同扩展名的旧文件（根脚本已经 `rm -rf "$DESKTOP_OUT"` 再 `mkdir`，所以根 `dist/desktop/` 本身是干净的，问题在 Tauri bundle 源目录）。但由于根脚本每次都清空 `$DESKTOP_OUT`，只要 Tauri bundle 目录中有多版本就会全部复制。

在 `build.sh` 和 `build.ps1` 的 desktop 收集逻辑中，改为只复制最新版本的文件（按修改时间排序取最新）：
```bash
# build.sh — 每种格式只取最新的一个
for ext_dir in msi nsis deb rpm appimage dmg; do
    # ... 原有逻辑，改为只 cp 最新的
done
```

实际上更简单的方式：Tauri 构建前清理 bundle 目录。但这需要修改 `scripts/dev.sh` 的 build 逻辑。考虑到根 `dist/desktop/` 每次都 `rm -rf` 重建，且用户主要关心的是插件包残留，desktop 的 Tauri bundle 累积是次要问题。**本次只修插件 pack 脚本，desktop 暂不动**（如果需要可以后续补）。

### 7. 清理现有残留文件

手动删除当前已存在的旧版本文件：
- `agent-aura-codex/dist/agent-aura-codex-0.1.0.tgz` 和 `.zip`
- `agent-aura-qwencode/dist/agent-aura-qwencode-0.1.0.tgz` 和 `.zip`
- `agent-aura-kimi-code/dist/agent-aura-codex-0.1.0.tgz` 和 `.zip`（误命名残留）
- 根 `dist/plugin/` 下对应的旧版本副本
